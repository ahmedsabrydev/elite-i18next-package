## Purpose

`packages/i18n/src/stubs/` reserves the `node` platform entry point for a runtime the release does
not implement. It exports a single factory that throws a clear, milestone-tagged error.

## When to Use It

You should not use it. It exists so that:

- the subpath `@faang/i18n/node` resolves in the package exports map, and
- code that reaches for an unimplemented runtime fails loudly at the call site instead of importing
  `undefined` and crashing somewhere unrelated.

## Usage

```ts
import { createNodeI18n } from '@faang/i18n/node'

createNodeI18n()
// Error: @faang/i18n/node is not implemented in v1. Track the v1.2 milestone.
```

## API

| Export | Subpath | Message | Milestone |
|---|---|---|---|
| `createNodeI18n` | `@faang/i18n/node` | `@faang/i18n/node is not implemented in v1...` | v1.2 |

Each function has return type `never`: it always throws.

## Failure Modes

It always throws `Error` with the message above. There is no silent no-op mode.
