This appendix enumerates every file tracked by Git, excluding generated types, the lockfile, the
`next-env.d.ts` shims, and the documentation content itself (which this page indexes). It is enforced
by `apps/docs/scripts/check-file-map.mjs`.

## Root Configuration

- `package.json` — workspace scripts (`verify`, `i18n:*`) and root dependencies.
- `pnpm-workspace.yaml` — declares the `packages/*` and `apps/*` workspaces.
- `turbo.json` — Turborepo task graph for build, test, typecheck, and budget.
- `tsconfig.base.json` — shared TypeScript compiler options extended by every workspace.
- `i18next.config.ts` — i18next-cli extraction, ignore globs, and type output.
- `.gitignore` — ignored build output, caches, and `.superpowers/`.
- `.github/workflows/ci.yml` — the CI pipeline that runs `pnpm verify`.

## Package Sources (`packages/i18n`)

### Entry and Config

- `packages/i18n/package.json` — package name, subpath exports map, and scripts.
- `packages/i18n/tsup.config.ts` — the esbuild/tsup bundling configuration.
- `packages/i18n/vitest.config.ts` — Vitest projects for node and jsdom tests.
- `packages/i18n/tsconfig.json` — package TypeScript project.
- `packages/i18n/scripts/check-budget.mjs` — gzip budget gate for the kernel and catalogs.

### Kernel (`core/`)

- `packages/i18n/src/index.ts` — the root entry point; re-exports the kernel surface.
- `packages/i18n/src/core/create-i18n.ts` — `createI18n`, the runtime constructor.
- `packages/i18n/src/core/resolve-config.ts` — `resolveConfig` and `loaderDefaults`.
- `packages/i18n/src/core/defaults.ts` — `BUDGETS`, `LOADER`, locale sets, and patterns.
- `packages/i18n/src/core/locale.ts` — `resolveLocale`, `dirFor`, `assertSupportedLocale`.
- `packages/i18n/src/core/types.ts` — every public type, including `I18nRuntime`.

### Cache and Loader (`cache/`, `loader/`)

- `packages/i18n/src/cache/lru.ts` — `LruCache`, the bounded recency cache.
- `packages/i18n/src/loader/memory.ts` — `MemoryStore`, the warm tier.
- `packages/i18n/src/loader/persistent.ts` — `PersistentStore`, the IndexedDB tier.
- `packages/i18n/src/loader/inflight.ts` — `InflightLoader` and `TimeoutError`.
- `packages/i18n/src/loader/backend.ts` — `namespaceChunkLoader` and `TieredBackend`.

### Observability, Catalogs, CLI (`obs/`, `catalogs/`, `cli/`)

- `packages/i18n/src/obs/events.ts` — `emit`, the swallowing event dispatcher.
- `packages/i18n/src/catalogs/index.ts` — `SHARED_NAMESPACES` and `SHELL_NAMESPACES`.
- `packages/i18n/src/cli/index.ts` — `CLI_PACKAGE`, `CLI_VERSION`, `CLI_COMMANDS`.

### React (`react/`)

- `packages/i18n/src/react/index.ts` — the `/react` entry point.
- `packages/i18n/src/react/provider.tsx` — `I18nProvider` and `I18nProviderProps`.
- `packages/i18n/src/react/hooks.ts` — `useT`, `useLocale`, `useI18nRuntime`.
- `packages/i18n/src/react/trans.tsx` — `Trans` with an injected `t`.
- `packages/i18n/src/react/context.ts` — `I18nContext`, `I18nContextValue`, `LocaleSnapshot`.

### Next.js (`next/`)

- `packages/i18n/src/next/index.ts` — the `/next` entry point.
- `packages/i18n/src/next/middleware.ts` — `i18nMiddleware`, `localeStaticParams`, `DEFAULT_COOKIE`.
- `packages/i18n/src/next/server.ts` — `createI18nServer`, `defineRouteI18n`.
- `packages/i18n/src/next/html.ts` — `getHtmlAttributes`.

### Vite (`vite/`)

- `packages/i18n/src/vite/index.ts` — the `/vite` entry point.
- `packages/i18n/src/vite/plugin.ts` — `i18nVitePlugin` and the manifest types.
- `packages/i18n/src/vite/routes.ts` — `localePrefix`, `matchLocaleFromPath`, `resolveLocaleOrNull`.

### Native (`native/`)

- `packages/i18n/src/native/index.ts` — the `/native` entry point.
- `packages/i18n/src/native/types.ts` — `CreateNativeI18nConfig`, `NativeController`, `NativeI18n`.
- `packages/i18n/src/native/ports.ts` — `NativeStorage`, `NativeLocalization`, `NativeRtl`, `AppStatePort`.
- `packages/i18n/src/native/create-native-i18n.ts` — `createNativeI18n`.

### Electron (`electron/`)

- `packages/i18n/src/electron/index.ts` — the `/electron` entry point.
- `packages/i18n/src/electron/types.ts` — `CreateElectronI18nConfig`, `ElectronController`, `ElectronI18n`.
- `packages/i18n/src/electron/ports.ts` — `ElectronStorage`, `ElectronLocale`, `ElectronSurfaces`, `ElectronMessenger`.
- `packages/i18n/src/electron/create-electron-i18n.ts` — `createElectronI18n`.

### Stores and Stubs (`store/`, `stubs/`)

- `packages/i18n/src/store/zustand.ts` — `createZustandLocaleStore` and `LocaleStore`.
- `packages/i18n/src/store/redux.ts` — `localeSlice`, actions, and selectors.
- `packages/i18n/src/stubs/node.ts` — `createNodeI18n` (throws until v1.2).

### Generated Types

- `packages/i18n/src/@types/i18next.d.ts` — i18next `CustomTypeOptions` augmentation.
- `packages/i18n/src/@types/resources.d.ts` — generated key tree for typed `t()`.
