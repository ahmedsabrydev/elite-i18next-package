## The AutoTypeTable Convention

Kernel and adapter pages render live type tables with FumaDocs' `AutoTypeTable` React Server
Component. Its `path` is **relative to the `apps/docs` working directory**, not to the current page:

```mdx
<AutoTypeTable path="../../packages/i18n/src/core/types.ts" name="I18nRuntime" />
```

- `path` points at the declaration file, e.g. `../../packages/i18n/src/core/types.ts`.
- `name` is the exported type name to render.
- The component is registered in `apps/docs/components/mdx.tsx` with a generator and a filesystem
  cache at `.next/fumadocs-typescript`.
- There is no `source.config.ts` companion; FumaDocs' Macro API (`defineDocs`) remains the sole
  content source.
