يعدّد هذا الملحق كل ملف يتعقّبه Git، باستثناء الأنواع المولَّدة وملف القفل وملفَّي `next-env.d.ts`
المُحاكيين ومحتوى التوثيق نفسه (الذي يفهرسه هذا الملف). ويفرضه
`apps/docs/scripts/check-file-map.mjs`.

## إعداد الجذر

- `package.json` — سكربتات مساحة العمل (`verify` و`i18n:*`) واعتماديات الجذر.
- `pnpm-workspace.yaml` — يعلن مساحتي العمل `packages/*` و`apps/*`.
- `turbo.json` — مخطط مهام Turborepo للبناء والاختبار وفحص الأنواع والميزانية.
- `tsconfig.base.json` — خيارات مُصرِّف TypeScript المشتركة التي توسّعها كل مساحة عمل.
- `i18next.config.ts` — استخراج i18next-cli وأنماط التجاهل ومخرَج الأنواع.
- `.gitignore` — مخرجات البناء والذاكرات المؤقتة و`.superpowers/` المتجاهَلة.
- `.github/workflows/ci.yml` — خط CI الذي يشغّل `pnpm verify`.

## مصادر الحزمة (`packages/i18n`)

### المدخل والإعداد

- `packages/i18n/package.json` — اسم الحزمة وخريطة المسارات الفرعية والسكربتات.
- `packages/i18n/tsup.config.ts` — إعداد الحزم عبر esbuild/tsup.
- `packages/i18n/vitest.config.ts` — مشاريع Vitest لاختبارات node وjsdom.
- `packages/i18n/tsconfig.json` — مشروع TypeScript للحزمة.
- `packages/i18n/scripts/check-budget.mjs` — بوابة ميزانية gzip للنواة والكتالوجات.

### النواة (`core/`)

- `packages/i18n/src/index.ts` — نقطة الدخول الجذرية؛ تعيد تصدير سطح النواة.
- `packages/i18n/src/core/create-i18n.ts` — `createI18n`، مُنشئ زمن التشغيل.
- `packages/i18n/src/core/resolve-config.ts` — `resolveConfig` و`loaderDefaults`.
- `packages/i18n/src/core/defaults.ts` — `BUDGETS` و`LOADER` ومجموعات اللغات والأنماط.
- `packages/i18n/src/core/locale.ts` — `resolveLocale` و`dirFor` و`assertSupportedLocale`.
- `packages/i18n/src/core/types.ts` — كل الأنواع العامة، بما فيها `I18nRuntime`.

### التخزين المؤقت والمُحمّل (`cache/` و`loader/`)

- `packages/i18n/src/cache/lru.ts` — `LruCache`، ذاكرة الأحدث استخداماً المحدودة.
- `packages/i18n/src/loader/memory.ts` — `MemoryStore`، الطبقة الدافئة.
- `packages/i18n/src/loader/persistent.ts` — `PersistentStore`، طبقة IndexedDB.

### المراقبة والكتالوجات والواجهة (`obs/` و`catalogs/` و`cli/`)
