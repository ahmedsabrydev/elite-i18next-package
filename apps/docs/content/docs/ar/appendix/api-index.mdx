## اصطلاح AutoTypeTable

تعرض صفحات النواة والمُهايئات جداول أنواع حية عبر مكوّن خادم React المسمّى `AutoTypeTable` من
FumaDocs. ومسار `path` **نسبي إلى دليل عمل `apps/docs`** لا إلى الصفحة الحالية:

```mdx
<AutoTypeTable path="../../packages/i18n/src/core/types.ts" name="I18nRuntime" />
```

- يشير `path` إلى ملف الإعلان، مثل `../../packages/i18n/src/core/types.ts`.
- و`name` هو اسم النوع المُصدَّر المراد عرضه.
- المكوّن مسجَّل في `apps/docs/components/mdx.tsx` مع مولِّد وذاكرة مؤقتة على نظام الملفات في
  `.next/fumadocs-typescript`.
- لا يوجد ملف `source.config.ts` مرافق؛ وتبقى واجهة Macro في FumaDocs (`defineDocs`) مصدر المحتوى
  الوحيد.
