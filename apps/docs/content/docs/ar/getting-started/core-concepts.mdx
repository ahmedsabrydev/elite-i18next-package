## كائن التشغيل

تُرجع `createI18n(config)` كائناً واحداً هو `I18nRuntime`:

| الحقل | النوع | الغرض |
|---|---|---|
| `instance` | كائن i18next من النوع `i18n` | المحرّك، يُنشأ عبر `createInstance()` فلا تتشارك التطبيقات حالة عامة |
| `config` | `ResolvedConfig` | الإعدادات بعد تطبيق القيم الافتراضية |
| `loadNamespace` | `(lng, ns) => Promise<void>` | تحميل مساحة أسماء واحدة في i18next |
| `prefetch` | `(lng, ns) => void` | استدعاء `loadNamespace` دون انتظار، مع إزالة التكرار وتحديد السقف |
| `has` | `(lng, ns) => boolean` | هل مساحة الأسماء موجودة في طبقة الذاكرة |
| `getHtmlAttributes` | `(lng) => { lang, dir }` | سمات آمنة للعرض الأول |
| `getT` | `(lng, ns?) => TFunction` | دالة ترجمة مثبّتة على لغة |

كائن التشغيل هو كائن التدويل الوحيد الذي يمرّره تطبيقك. وهو معرّف في
`packages/i18n/src/core/types.ts` ومبنيّ في `packages/i18n/src/core/create-i18n.ts`.

## الكتالوجات ومساحات الأسماء

**الكتالوج** مجلد من ملفات JSON لمساحات الأسماء، بمجلد واحد لكل لغة. و**مساحة الأسماء** ملف JSON
واحد ووحدة شبكة أو وحدة `import()` واحدة. تشحن الحزمة خمس مساحات أسماء مشتركة — `common`
و`errors` و`auth` و`validation` و`datetime` — معلنة في `packages/i18n/src/catalogs/index.ts`.

اثنتان منهما **قشرة** (`common` و`errors`): صغيرتان، مطلوبتان دائماً، وقابلتان للتضمين في العرض
الأول. أما البقية فهي **كسولة**: يحمّلها المسار الذي يحتاجها.

## القشرة مقابل التحميل الكسول

يستهدف التصميم شبكات الجيل الثاني بمعاملة كل مساحة أسماء كوحدة مستقلة قابلة للتخزين المؤقت:

- مجموعة مساحات القشرة محدودة بميزانية gzip (12 كيلوبايت مجمّعة لـ `common` و`errors`)؛
- مساحة الأسماء الكسولة الواحدة محدودة بـ 16 كيلوبايت gzip؛
- حزمة النواة محدودة بـ 12 كيلوبايت gzip.

يفرض السكربت `packages/i18n/scripts/check-budget.mjs` ميزانيات الكتالوجات؛ كما يوجد جدول
القيم في الشيفرة باسم `BUDGETS` في `packages/i18n/src/core/defaults.ts`.

## تحديد اللغة

على الويب، يملك المسار اللغة: `/en/...` و`/ar/...`. تقبل `resolveLocale` في
`packages/i18n/src/core/locale.ts` وسم لغة، وتتحقق منه بنمط آمن، وتطابقه دون حساسية لحالة
الأحرف مع القائمة المسموحة، ثم ترجع إلى اللغة الافتراضية. وتُسقط `dirFor` الوسم إلى `'ltr'`
أو `'rtl'` باستخدام المجموعة `RTL_LOCALES` (`ar` و`he` و`fa` و`ur`).

لا يرسم الكوكي ولا ترويسة `Accept-Language` الصفحة أبداً؛ بل يقودان إعادة توجيه فقط. وهذه قاعدة
انعدام الوميض عملياً.

## مرآة المتجر

عند استخدام Zustand أو Redux، يحتفظ المتجر بـ**مرآة** لبيانات اللغة فقط:
`{ lng, dir, isRtl, status }`. ولا يحتفظ بالنصوص إطلاقاً — فالنصوص تبقى في i18next. المرآة
معرّفة كـ `LocaleSnapshot` في `packages/i18n/src/react/context.ts`، وتُعكس عبر `LocaleStore`
(Zustand) و`LocaleState` (Redux).
