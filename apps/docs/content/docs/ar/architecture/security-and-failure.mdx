## إدخال اللغة غير موثوق

كل لغة تصل من مسار أو كوكي أو ترويسة تمرّ عبر `resolveLocale` في
`packages/i18n/src/core/locale.ts`. وهي:

1. ترفض كل ما ليس وسم لغة على شكل BCP-47 عبر النمط `SAFE_LNG`
   (`/^[a-zA-Z]{2,3}(-[a-zA-Z0-9]{2,8})*$/`)؛
2. تُسقط المنطقة وتصغّر الأساس؛
3. تطابقه مع قائمة اللغات المسموحة؛
4. ترجع إلى الافتراضي عند أي عدم تطابق.

ولأن القيمة تُتحقق قبل إدراجها في هدف إعادة التوجيه، لا يمكن لطلب مثل
`Accept-Language: ../../etc/passwd` أن يصبح اجتياز مسار. والمساعد نفسه تستخدمه وسيطة Next
ومطابقات مسارات Vite و`getHtmlAttributes` في النواة.

## أمان إعادة التوجيه

يبني `i18nMiddleware` (`packages/i18n/src/next/middleware.ts`) إعادة توجيهه بالشكل
`/${locale}${request.pathname}${request.search}`. واللغة دائماً عضو في مصفوفة `locales`
المضبوطة، فلا يمكن للمهاجم التحكم بالبادئة؛ ولا يُلحق إلا المسار الأصلي الذي يملكه الإطار
أصلاً.

## أنماط الفشل

| الفشل | السلوك |
|---|---|
| كتالوج 404 أو خطأ شبكة | يُحسم المُحمّل إلى `undefined` وتُعرض اللغة الاحتياطية |
| JSON مشوّه | `undefined` وتُعرض اللغة الاحتياطية |
| تجاوز التحميل `LOADER.timeoutMs` (3000ms) | يُصدر `ns.timeout` ثم `undefined` |
| رمي خطأ في `onEvent` | تبتلعه `emit` ويستمر العرض |
| عدم توفر IndexedDB (SSR أو الوضع الخاص) | يُحسم `PersistentStore` إلى `undefined` ويكون بلا أثر |
| حجب `indexedDB.open` | يُحسم إلى `undefined` وتُتخطى الطبقة |
| مفتاح مفقود بلا احتياطي | يُرجع i18next المفتاح نفسه (`returnNull: false`) |

لا شيء من هذا يرمي خطأً في شيفرة التطبيق. فـ `loadNamespace` تُحسم دائماً ولا تُرفض عند فشل
كتالوج.

## تهريب الإدخال

قيمة `interpolation.escapeValue` هي `true`، فتُهرَّب القيم المُدخلة إلى النص قبل وصولها إلى DOM.
وهذا يحمي النمط الشائع `t('greeting', { name: userInput })` في React. وإن احتجت HTML خاماً
عمداً فاستخدم مكوّن `<Trans>` بدل الإدخال النصي.

## أهداف غير مقصودة

- لا حدث فشل عام. الفشل صامت بالتصميم؛ والمهلات وحدها قابلة للمراقبة.
- لا عاصفة إعادة محاولة. يعيد `InflightLoader` المحاولة مرة واحدة بعد تأخير قصير ثم يستسلم.
- لا عرض أول من كوكي. انظر [العرض دون وميض](/architecture/zero-flicker).
- لا أسرار ولا بيانات اعتماد في أي مكان في وقت التشغيل؛ لا تقرأ الحزمة إلا ملفات كتالوج عامة.
