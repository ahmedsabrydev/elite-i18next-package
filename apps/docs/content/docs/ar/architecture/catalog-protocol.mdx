## الوحدة

الوحدة الذرّية في بروتوكول الكتالوج ملف JSON واحد:

```
catalogs/en/common.json
catalogs/ar/common.json
```

الملف الواحد مساحة أسماء واحدة ولغة واحدة وطلب شبكة واحد ومدخل تخزين مؤقت واحد. ولا تُجمَّع أي
نصوص «على سبيل الاحتياط». ويحمّل المسار مساحات الأسماء التي يحتاجها فقط.

## مساحات الأسماء المشتركة ومساحات القشرة

تملك الحزمة خمس مساحات أسماء مشتركة، معلنة في `packages/i18n/src/catalogs/index.ts`:

```ts
export const SHARED_NAMESPACES = ['common', 'errors', 'auth', 'validation', 'datetime'] as const
export const SHELL_NAMESPACES = ['common', 'errors'] as const
```

- **مساحات القشرة** (`common` و`errors`) صغيرة ومطلوبة في كل الصفحات تقريباً، وهي مرشّحة للحضور
  في العرض الأول.
- **المساحات الكسولة** (`auth` و`validation` و`datetime` وأي مساحة تخص التطبيق) يحمّلها المسار
  الذي يستخدمها، عادةً عبر `prefetch` عند المرور أو الخمول.

## بنية المجلدات

بشكل افتراضي يقرأ المُحمّل `${catalogs.shared}/${lng}/${ns}.json` و
`${catalogs.public}/${lng}/${ns}.json`، ويجلب اختيارياً `${publicPath}/${lng}/${ns}.json` عند
ضبط `publicPath`. تفاصيل الترتيب والنقل في `packages/i18n/src/loader/backend.ts`.

## الهوية والبصمات

يمكن تعريف الكتالوج ببصمة محتواه لتُبطَل المخابئ بدقة. وتُنتج إضافة Vite
(`packages/i18n/src/vite/plugin.ts`) بياناً:

```json
{
  "version": 1,
  "locales": {
    "en": { "common": { "hash": "3f2a9c1d0b7e", "bytes": 812 } }
  }
}
```

البصمة هي أول 12 محرفاً ست عشرياً من SHA-256 للملف، و`bytes` هو طول الملف بالبايت الخام. ويقبل
المخزن الدائم وسيط `hash` لرفض السجل القديم (انظر
[المخزن الدائم](/packages/loader/persistent)).

## الميزانيات

لكل وحدة كتالوج ميزانية gzip تفرضها `packages/i18n/scripts/check-budget.mjs` وتُعكس باسم
`BUDGETS` في `packages/i18n/src/core/defaults.ts`:

| الوحدة | الميزانية |
|---|---|
| حزمة النواة (`dist/index.js`) | 12 كيلوبايت gzip |
| كتالوجات القشرة (`common` + `errors` مجمّعة) | 12 كيلوبايت gzip |
| مساحة أسماء كسولة واحدة | 16 كيلوبايت gzip |
| البيان | 1.5 كيلوبايت gzip |

ويُفشل `pnpm budget` البناء إذا تجاوز أي كتالوج أو النواة ميزانيته.

## لماذا لا ملف واحد

ملف `translations.json` واحد لكل لغة يفرض على كل زائر تنزيل كل نص لكل ميزة. ويقايض بروتوكول
الكتالوج قليلاً من المحاسبة بحِمل على مستوى المسار، وهو ما يجعل التوصيل الآمن على شبكات الجيل
الثاني ممكناً.
