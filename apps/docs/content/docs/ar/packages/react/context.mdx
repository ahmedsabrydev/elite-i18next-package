## الغرض

يُعلن `packages/i18n/src/react/context.ts` سياق React والنوعين الذي يحملهما. وهو صغير عمداً: السياق
مرآة للقراءة فقط لبيانات اللغة، لا مخزن للنصوص المترجمة.

## متى تستخدمه

استهلكه عبر الخطافات. واستورد الأنواع عندما تكتب مكوّناً يستقبل لقطة كخاصية، أو عندما تبني مُزوّداً
بديلاً.

## الصادرات

| التصدير | النوع | المعنى |
|---|---|---|
| `I18nContext` | سياق | `I18nContextValue \| null`، الافتراضي `null` |
| `I18nContextValue` | نوع | ما ينشره المُزوّد |
| `LocaleSnapshot` | نوع | مرآة اللغة وقت العرض |

### I18nContextValue

| الحقل | النوع | ملاحظات |
|---|---|---|
| `runtime` | `I18nRuntime` | زمن التشغيل المشترك |
| `locale` | `string` | اللغة الفعّالة |
| `snapshot` | `LocaleSnapshot` | البيانات المشتقة |
| `navigate` | `(href: string) => void \| undefined` | جسر الموجّه الاختياري |

## الاستخدام

```tsx
import { useContext } from 'react'
import { I18nContext } from '@faang/i18n/react'

const ctx = useContext(I18nContext)
if (ctx) ctx.snapshot.dir
```

## لماذا تعيش النصوص في مكان آخر

المحتوى المترجم تملكه i18next لا هذا السياق. ونسخ النصوص إلى حالة React سيكرّر المخزن المؤقت ويكسر
قواعد الإدراج والجمع في i18next ويعرّض النص للتقادم بعد تبديل اللغة. والسياق يحمل فقط ما يحتاجه React
للتصميم الصحيح:

- `lng` — للمفاتيح والروابط وسمات `lang`،
- `dir` — اتجاه CSS،
- `isRtl` — قيمة منطقية مريحة،
- `status` — ما إذا كانت مساحة الأسماء الافتراضية متوفرة بعد.

أما النصوص الفعلية فيقرأها `useT` المدعومة بنسخة i18next.

## السلوك والحالات الحدّية

- القيمة الافتراضية لـ `I18nContext` هي `null`؛ وتعتبر الخطافات `null` بمثابة "المُزوّد مفقود" وترمي.
- لـ `status` ثلاث قيم ممكنة (`'hydrated' | 'switching' | 'loading-ns'`)، لكن المُزوّد يحسب حالياً
  `'hydrated'` أو `'loading-ns'` فقط؛ و`'switching'` جزء من النوع العام للمُهايئات التي تتعقب
  الانتقالات.
- تُعاد اللقطة إنشاؤها كلما تغيّر `[locale, runtime]`؛ وهي ليست اشتراكاً حياً.

## أنماط الفشل

قراءة السياق مباشرةً تُرجع `null` خارج مُزوّد، وهي نتيجة صحيحة لا ترمي. وسلوك الرمي محصور عمداً في
الخطافات.
