## الغرض

يحتوي `packages/i18n/src/loader/backend.ts` نقل المُحمّل الافتراضي. وهو يحسم مساحة أسماء بتجربة
الطبقات بالترتيب — الذاكرة الدافئة، ثم IndexedDB، ثم استيراد ديناميكي (مع مسار `createRequire` في
Node)، ثم `fetch` — ويخزّن النتائج الناجحة في الطبقات الأدنى. و`namespaceChunkLoader` هو المصدر
الافتراضي، و`TieredBackend` هو المُنسّق.

## متى تستخدمه

يوصّل `createI18n` كائن `TieredBackend` لك. ابنِ واحداً مباشرةً لتخصيص طبقة (مثلاً مخزن دائم مخصص)
أو لتزويد `NamespaceLoader` مخصص مع الحفاظ على إزالة التكرار والتخزين المؤقت والقياسات.

## الاستخدام

```ts
import { TieredBackend, namespaceChunkLoader } from '@faang/i18n'

const backend = new TieredBackend({
  config: resolved,                 // ResolvedConfig
  loader: namespaceChunkLoader(resolved),
  fetcher: fetch,                   // اختياري
})

await backend.load('en', 'common')
backend.has('en', 'common') // true بعد التحميل
backend.prefetch('ar', 'common')  // إطلاق بلا انتظار
```

### namespaceChunkLoader

يُرجع `namespaceChunkLoader(config)` دالة `NamespaceLoader` تبني المُحدِّدات المرشحة من
`config.catalogs`:

```ts
const candidates = shared
  ? [`${shared}/${lng}/${ns}.json`, `${publicPath}/${lng}/${ns}.json`]
  : [`${publicPath}/${lng}/${ns}.json`]
```

ويجرّب كل مرشح عبر `importJson`، ثم عند ضبط `config.publicPath` يلجأ إلى:

```ts
fetch(`${config.publicPath}/${lng}/${ns}.json`)
```

فقط الاستجابة غير `ok` أو الرمي يُنتج `undefined`.

## نقل createRequire في Node

لـ `importJson` مساران. في Node (`process.versions?.node`) يستورد `node:module` ديناميكياً ويستخدم
`createRequire(import.meta.url)` مع `require.resolve(specifier)`. والاستيراد الديناميكي موسوم بـ
`/* @vite-ignore */ /* webpackIgnore: true */ /* turbopackIgnore: true */` كي تتركه المُجمِّعات. وإن
فشل الحسم انتقل إلى `import(specifier)` الديناميكي العادي، وهو موسوم أيضاً، ويفكّ `mod.default ?? mod`.
وكل خطوة داخل `try/catch` وتُرجع `undefined` عند الفشل. ولهذا تقبل المُجمِّعات (بما فيها Next/Turbopack)
الوحدة: لا `require` ديناميكي بلا وسم ولا استيراد JSON ساكن قد يُزيله `esbuild`/`tsup`.

## السلوك والحالات الحدّية

- ترتيب الطبقات عند الغياب: `inflight.run` ← `persistent.get` ← `loader(lng, ns)` ← ثم عند النجاح
  `persistent.set`. وإصابة الذاكرة تقطع كل شيء وتُصدر `ns.cache_hit`.
- الغياب (موارد غير صحيحة) يُرجع `undefined` **دون** تخزين مؤقت، فتـُعاد المحاولة في الاستدعاء التالي.
- التحميل الناجح يضبط الذاكرة ثم يُصدر `ns.load` مع `ms` (زمن الجدار) و`bytes`
  (`JSON.stringify(...).length`، أو `undefined` إن رمى، مثلاً لبيانات دائرية).
- `prefetch` إطلاق بلا انتظار عمداً؛ لا يُرفض للمستدعي أبداً.
- يعكس `has` الطبقة الدافئة فقط؛ فمساحة أسماء موجودة في IndexedDB تظل تُرجع `false`.

## أنماط الفشل

- تُلتقط مهلة `InflightLoader` وتُصدر كـ `ns.timeout` باستخدام `lng`/`ns` من الخطأ وتُحسم إلى
  `undefined`.
- تُلتقط الأخطاء غير المتعلقة بالمهلة وتُحسم إلى `undefined` **بلا** حدث (تأجيل مسجَّل).
- لا يُرفض `load` أبداً.
