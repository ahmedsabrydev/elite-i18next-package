## الغرض

يحجز `packages/i18n/src/stubs/` نقطة دخول منصة `node` لزمن تشغيل لا ينفّذه الإصدار. وتُصدّر
مُنشئاً واحداً يرمي خطأً واضحاً موسوماً بمرحلته.

## متى تستخدمه

لا ينبغي أن تستخدمه. فهو موجود كي:

- يُحلّ المسار الفرعي `@faang/i18n/node` في خريطة صادرات الحزمة، و
- تفشل الشيفرة التي تمدّ يدها إلى منصة غير منفَّذة بصوت عالٍ عند موضع الاستدعاء بدل استيراد
  `undefined` والانهيار في موضع غير ذي صلة.

## الاستخدام

```ts
import { createNodeI18n } from '@faang/i18n/node'

createNodeI18n()
// Error: @faang/i18n/node is not implemented in v1. Track the v1.2 milestone.
```

## واجهة البرمجة

| التصدير | المسار الفرعي | الرسالة | المرحلة |
|---|---|---|---|
| `createNodeI18n` | `@faang/i18n/node` | `@faang/i18n/node is not implemented in v1...` | v1.2 |

نوع إرجاع كل دالة هو `never`: أي أنها ترمي دائماً.

## أنماط الفشل

ترمي دائماً `Error` بالرسالة أعلاه. ولا يوجد وضع لا أثر له صامت.
